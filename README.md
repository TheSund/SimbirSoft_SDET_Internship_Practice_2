# Задание 2 для Практикума по SDET от SimbirSoft (ноярь 2025)
Цель задания: создать проект автотестов на Python для тестирования сервиса API.
## Установка проекта и запуск проекта
1. Клонировать репозиторий локально
2. Установить зависимости (через `pip install` или с помощью Install dependancies внутри Pycharm)
3. Запускать `pytest` через Terminal

## Чек-лист, реализуемый в проекте
Репозиторий тестируемого сервиса API: https://github.com/bondarenkokate73/simbirsoft_sdet_project

Чек-лист:
1. Создание сущности.
2. Получение сущности.
3. Обновление сущности.
4. Получение списка сущностей.
5. Удаление сущности.
